LangGraph: Cyclical Multi-Agent Workflows

Overview

LangGraph is an open-source framework by LangChain designed for creating controllable agent and multi-agent workflows. Unlike standard Directed Acyclic Graphs (DAGs) found in traditional pipeline engines, LangGraph supports cyclical computations, making it ideal for agentic loops, self-correcting RAG systems, human-in-the-loop workflows, and stateful memory.

State and StateGraph

The central abstraction in LangGraph is the StateGraph. Each workflow defines a shared state schema, typically declared as a TypedDict or Pydantic model. As execution flows through the graph, nodes return dictionary updates that modify or append to this central state using reducer functions like operator.add.

Nodes, Normal Edges, and Conditional Edges

Workflows in LangGraph consist of three main primitives:

  • Nodes: Python functions or runnables that take the current graph state as input and return updated state attributes.
  • Normal Edges: Direct deterministic transitions routing from one node straight to the next node.
  • Conditional Edges: Routing functions that inspect the current graph state and determine which downstream node should execute next based on business logic, LLM decisions, or retry count thresholds.

Corrective RAG (CRAG) with LangGraph

In a Corrective RAG workflow, retrieved documents are graded by an evaluator node. If documents are deemed irrelevant, a conditional edge routes the flow to a query rewriting node to re-retrieve with a modified query, rather than generating a hallucinated or inaccurate response.
